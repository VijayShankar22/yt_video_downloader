# yt_video_downloader
A Python-based command-line tool for downloading YouTube videos in your desired format with the highest possible quality and audio. This tool uses yt-dlp for handling YouTube video downloads.

## Features
- **Format Listing**: Lists all available formats for a YouTube video.
- **Merge Video and Audio**: Downloads the best audio and merges it with the selected video format into an MP4 file.
- **4K Downloads**: Downloads videos in 4K quality with high bitrate and audio.

##Installation

clone the repository:

```bash
git clone https://github.com/VijayShankar22/yt_video_downloader.git
cd yt_video_downloader
cd cli
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

##usage

Run the script:

```bash
Python yt_video_downloader.py
```
